# Heidy-IA 🤖📚

## Inteligencia Artificial para Tareas

Heidy-IA es una inteligencia artificial creada para ayudar a los estudiantes con sus tareas, ejercicios y trabajos escolares.

### Funciones

- 📚 Ayuda con tareas escolares
- 🧠 Explicaciones paso a paso
- ➗ Matemáticas
- 🔬 Ciencias
- 🌎 Historia y geografía
- ✍️ Trabajos y preguntas
- 📸 Análisis de fotos de tareas
- 💬 Conversación con la inteligencia artificial

### Objetivo

Ayudar a los estudiantes a comprender sus tareas y aprender de manera sencilla.
